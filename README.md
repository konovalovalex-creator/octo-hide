# Octo Hide & Seek — «Осьминожьи прятки»

Мультиплеерные прятки за осьминога, который маскируется под окружение.
Сейчас в репозитории **прототип №1**: один осьминог без сети — движение, щупальца и маскировка.

## Требования

- Unity **6** (6000.x), шаблон **Universal 3D (URP)**
- Input System (есть в шаблоне; поддерживается и старый Input Manager)

## Как запустить

1. Создайте в Unity Hub новый проект по шаблону **Universal 3D** прямо в папке этого репозитория
   (или скопируйте `Assets/OctoHide` в уже существующий URP-проект).
2. Дождитесь компиляции скриптов и шейдеров.
3. Меню **OctoHide → Build Prototype Scene** — сгенерирует текстуры, материалы и сцену
   `Assets/OctoHide/Scenes/Prototype.unity`.
4. Нажмите **Play**.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD | Ползти (в том числе по стенам) |
| Space | Реактивный рывок |
| Мышь / колесо | Камера / зум |
| E | Скопировать окрас поверхности под собой |
| C | Ручная палитра |
| R | Обычный окрас |
| Z / X | Папиллы: гладкая / бугристая кожа |
| 1–4 | Позы: обычная, камень, распластаться, вытянуться |
| F1 / F3 | Подсказки / отладка заметности |
| Esc | Освободить курсор |

## Что проверить

- Встаньте на участок дна, нажмите **E** и замрите — узор должен совпасть с поверхностью.
- Сдвиньтесь — узор поедет вместе с телом, индекс заметности вырастет.
- Позы «камень» и «распластаться» прячут силуэт.
- Переползание на стену (кирпичная «стена водорослей» в конце сцены).

## Структура

```
Assets/OctoHide/
  Scripts/Input        — обёртка ввода
  Scripts/Octopus      — движение (OctopusController), процедурные щупальца (OctopusTentacles)
  Scripts/Camouflage   — кожа (OctopusSkin), поверхности (CamoSurface), заметность (ConspicuityMeter)
  Scripts/CameraRig    — камера от третьего лица
  Scripts/UI           — временный HUD
  Shaders              — кожа осьминога и окружение (общая триплэнарная проекция)
  Editor               — генератор тестовой сцены
```

## Как устроена маскировка

Окружение и кожа используют одинаковую триплэнарную проекцию узора в мировых координатах.
При копировании запоминается поза осьминога; шейдер кожи пересчитывает каждую точку тела
в мировые координаты «на момент копирования». Поэтому неподвижный осьминог совпадает
с поверхностью идеально, а при движении узор едет вместе с телом и выдаёт его.
