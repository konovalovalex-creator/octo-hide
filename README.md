# Octopus Evolution: Rise of the Kraken

3D-симулятор осьминога: охота, рост и эволюция от крошечного осьминога до гигантского Кракена.
Unity 6 + URP, платформы — Android и Windows (Steam). Стиль — реалистичный подводный мир.

Сейчас идёт **этап 0** плана MVP: структура проекта, подводный рендер, сборки под обе платформы.

## Как запустить

1. Откройте папку репозитория в Unity Hub (Unity 6.6, шаблон URP).
2. Меню **OctoEvo → Setup Project (Android + Steam)** — один раз.
3. Меню **OctoEvo → Build Reef Scene** — сгенерирует текстуры, меши и сцену `Assets/OctoEvo/Scenes/Reef.unity`.
4. **Play**.

Сборки: **OctoEvo → Build → Android APK** (нужен модуль Android Build Support) и **Build → Windows (Steam)**.
Готовые файлы появляются в папке `Builds/` (не попадает в git).

## Управление (временное, ПК)

WASD — двигаться, Space — рывок, мышь — камера, E — маскировка под поверхность,
1–8 — позы, Q — закрыть глаза, F1 — подсказки, Esc — освободить курсор.

## Структура

```
Assets/OctoEvo/
  Core/       ввод, общие сервисы                     (сборка OctoEvo.Core)
  Gameplay/   осьминог, маскировка, существа, мир     (OctoEvo.Gameplay)
  UI/         интерфейс                               (OctoEvo.UI)
  Editor/     генераторы сцены и ассетов, сборки      (OctoEvo.Editor)
  Shaders/    подводная оптика, окружение, кожа, лучи, поверхность воды
  Generated/  то, что создаёт Build Reef Scene
```

## Подводная оптика

Все наши шейдеры используют общий `OctoUnderwater.hlsl`: солнечный свет гаснет с глубиной по каналам
(красный первым), каустика на поверхностях, поглощение и рассеяние по пути до камеры.
Параметры воды — в компоненте `UnderwaterEnvironment` на объекте `Underwater` в сцене.

Временные текстуры генерируются процедурно; позже заменяются сканами (Poly Haven / ambientCG) —
достаточно подставить их в материалы из `Generated/Materials`.
